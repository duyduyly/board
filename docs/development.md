# Phát triển và mở rộng Card Atlas

## Chuyển dự án Markdown cũ sang editor HTML

Trình chuyển đổi chạy cục bộ bằng Node.js, không tải dữ liệu lên mạng. Trong thư mục
repository, chạy `npm ci`, sau đó dùng:

```powershell
node scripts/convert-markdown-files.mjs --out "D:/duong-dan/thu-muc-ket-qua-moi" "D:/duong-dan/du-an-cu.json"
```

Thư mục kết quả phải chưa tồn tại. Công cụ không ghi đè tệp đầu vào: `backup/` chứa
bản gốc đúng từng byte, `converted/` chứa JSON đã chuyển đổi, và `report.json` ghi
SHA-256 cùng cảnh báo theo từng note. Mở tệp trong `converted/` bằng chức năng nhập
JSON và kiểm tra trước khi thay bản đang dùng. Mermaid được giữ dưới dạng mã nguồn
trong file và được vẽ ở màn hình đọc (E056);
HTML cũ và ảnh ngoài được giữ dưới dạng nguồn có chú thích, không tự thực thi hoặc
tải ảnh. Không xóa bản gốc trước khi đã kiểm tra kết quả.

E049 (04_upgrade_ui) softens the Pencil Notebook chrome with tokens only, all in `notebook.css`: radius scale `--radius-xs/sm/md/segment/lg/xl/pill` (4/6/8/11/12/14/999px) with `--sketch-radius` kept as an alias of `--radius-md`; chrome shadows `--surface-shadow`, `--dialog-shadow`, `--control-shadow` (card shadow `--pencil-shadow` unchanged); `--motion-fast`/`--motion-ease` for control transitions (disabled under reduced motion). `app.js` adds the temporary `theme-switching` class on `<html>` around the `data-theme` change and `base.css` zeroes transitions under it, so theme switches repaint instantly. Format dock: `inspector-grid.css` shows tab labels (`.inspector-tab-label`) and field names (`.format-property-name`) once the dock container is at least 321px wide; at 320px or less they stay screen-reader names only (same container breakpoint as the single-column grids). Detail editor space: the HTML block-editor mode bar is compact and, from 701px, the icon actions overlay its row so the editor canvas keeps at least 300px at 1000x800 (`detail-editor-space.spec.mjs`). Default card radius is `PLAIN_CARD_RADIUS = 6` in `detail/appearance.js` (cards without `shape`); `rectangle`/`square` use `SQUARE_SHAPE_RADIUS = 2`; other shapes keep `appearanceDefaults.radius`. `appearanceWith` drops a derived radius from the patched appearance unless the card already stored one or the patch sets it, so the default never leaks into JSON. The Mind banner moves up (`bottom: 84px`) at 1150px or narrower so it clears the zoom bar.

E050 (06_mindmap_focus_pencil_ui): branch Focus is session state in `app.js` (`focusBranch`), never in JSON, history, store or recovery. `graph/branch-focus.js` `branchCards(project, rootId, follow)` is pure: BFS over `projectIndex(project).outgoing` with a `seen` Set (cycle, self and duplicate safe), unknown root returns an empty Set, the index Maps are only read. `canvas/adapter.js` `syncFocus` passes `follow` per view: Note Board follows every relation, Mind only `relationKind(r) === 'branch'` (the collapse/Convert tree), so reference links do not pull other branches in. `render()` passes `focusRoot` (selected card id or null) to `adapter.sync`; `paintFocus` toggles `focus-dimmed` on the card overlays and, inside one `cy.batch`, on edges unless both ends are in the branch (stylesheet rule `edge.focus-dimmed`, opacity .15; `.graph-card.focus-dimmed` in `workspace.css`, opacity .25, no transition, geometry and pointer events untouched). It runs on both the fast and the full sync path, memoised on `(project, view, root, collapsed)` and exits at once when no root and nothing painted, so pan, zoom, locale and selection of the same root do nothing. Both `[data-action=focus]` and `[data-panel-action=focus]` are toggles: `aria-pressed` and `title` (`focus` or `focusBranchExit`) follow `focusBranch`, pressed style uses `--active-background` plus accent border. Turning it on still reveals the selection and centers the card (`adapter.focus`, so the editor.spec centering contract holds); turning it off keeps the viewport. A relation keeps the old center-on-relation behavior and does not enter the mode. Exits: pressing again; Escape (after the input, feedback, Home and Detail guards, keeps the selection, a second Escape clears it as before); `render()` when selection is no longer a card. View switch, Undo/Redo, collapse and layout preview keep it. Dimmed cards stay editable and draggable. Tests: `branch-focus-core.test.mjs`, `branch-focus.spec.mjs`.

E053 (07_funny_animation): optional decorative pet (`ui/pixel-cat.js`, `css/pixel-cat.css`), chosen in the ? menu (`#pet-choice`: Cat default, Dog, Off; `?pet=cat|dog|off`), session memory only (no storage). One fixed overlay (`z-index: 30`, below the Format dock 40/70, toolbar and menu 60, toast 1000), `pointer-events: none` except the pet itself; it never takes focus and never touches the model or store. Under `navigator.webdriver` it mounts only with `?cat=1`, so tests opt in explicitly. Movement is a pure planner (`planNext`, `stepPosition`, `rampFactor`) driven by one rAF while moving; idle uses timers; hidden tab and `prefers-reduced-motion` halt it. Sprite strips are horizontal squares (frame size = image height). Cat: 7 frames, walk 1-2-3-2. Dog (`scripts/make-dog-sprites.py` from `walking_spritesheet.png` + `running_spritesheet.png`): 16 frames, 0 stand/turn, 1 jump, 2-9 walk loop, 10-15 run loop, every second source frame, played by CSS `steps()`; each frame is held for `frameMs` (100) and the speed is derived from the stride (`lockedCadence`) so frame changes land on whole vsync intervals and feet do not slide. A `step-end` timing function must sit inside every keyframe that has values. Specs: `pixel-cat.spec.mjs`, `pixel-pet-choice.spec.mjs`, cores `pixel-cat-core.test.mjs`.

E056 (10_media_mermaid_video) reading-screen media. (1) Import HTML converts `<img src="data:image/(png|jpeg|webp|gif);base64,…">` into attachments (`imageFromDataURL` in `detail/attachments.js`, hook `parseDocument(html, { dataImage })`, staged in `detail/html-import.js` and merged into the card only on Accept); invalid or oversized images are listed under removed parts. Limits: HTML without data-URL payloads ≤ 1,000,000 bytes, whole paste ≤ 10 MiB, each image ≤ 10 MiB. The HTML source mode and the JSON contract still reject data URLs. (2) Mermaid: `pre > code.language-mermaid` blocks, including `data-origin="legacy-mermaid"`, are drawn in the reading frame by `detail/mermaid-render.js`. mermaid 12.3.0 is built by `scripts/build.mjs` into `assets/vendor/mermaid/` (split chunks, about 5.3 MB on disk, about 0.8 MB loaded for a first flowchart, lazy-imported only when a document has a diagram; licences in `assets/vendor/mermaid/LICENSES.txt`). elkjs (EPL-2.0) is stubbed out of the bundle, so `layout: 'dagre'` is set explicitly. Rendering happens in the parent page because the sandboxed frame runs no script: sources must pass `isSafeDiagramSource` (`graph/diagram-policy.js`: no `%%{init}`, frontmatter, `style`, `classDef`, `click`, URLs), at most 20,000 characters per block and 20 diagrams per document; `securityLevel: 'strict'`, `htmlLabels: false`; the SVG is sanitized by DOMPurify (no `foreignObject`) before `importNode`. Colours come from the frame's `--doc-*` tokens. The block editor and the standalone HTML export keep the source. (3) YouTube: `<a class="board-video" href="…">` whose href yields a valid id (`graph/youtube.js`: youtube.com watch/shorts/embed, youtu.be) becomes a 16:9 click-to-play placeholder in the Overview reading frame only (`videos: true`); elsewhere it stays a link. The player (`https://www.youtube-nocookie.com/embed/<id>`) is an iframe in the parent `.markdown` host laid over the placeholder (`detail/video-embed.js`) and is repositioned through `sizeFrame`/`setDocumentScale`, with no scroll listener. Nothing is fetched before the user presses play; no thumbnail is loaded. Re-rendering the panel (theme, locale, Apply, tab switch) stops playback. The page has no CSP today; if one is added it needs `frame-src https://www.youtube-nocookie.com`. Official docs: https://mermaid.js.org/config/usage.html and https://developers.google.com/youtube/player_parameters.

E057 (11_copy_paste_cards) copy, paste and duplicate on the Canvas. `graph/copy-cards.js` is pure: `copyCards(project, ids)` snapshots the selected cards, the relations whose two ends are selected and their Mind Map geometry; `pasteCards(draft, snapshot, { offset, newId })` appends copies with new ids, a new creation stamp, no pin, and both views shifted by the offset. `app.js` keeps the snapshot in session memory only (never the system clipboard, never exported): Ctrl/Cmd+C copies, Ctrl/Cmd+V pastes (each paste is one command and is staggered by 36 px), Ctrl/Cmd+D and the Duplicate button in the selection toolbar duplicate without replacing the copy buffer. Copies are not added to groups.

## Query cache

E023: app giữ selectedCards Set session bên cạnh primary selection của Detail. canvas/multi-selection nhận ports, giữ preview DOM/Cytoscape và một pointer transaction; cancel trên Escape/capture/blur/viewport/sync. adapter.paintSelection chỉ cập nhật các IDs trong tập cũ/mới. graph/move-cards chạy trong một commit, bỏ pins/dedup, chỉ active-view positions; khi kéo Card có Mind fallback thì materialize vị trí Mind cũ để không kéo theo view kia.
