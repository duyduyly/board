# Editor design

Reference: editor-concept.png, generated with built-in Image Gen for the full Card Atlas editor (toolbar, search sidebar, dotted graph canvas and detail panel).

White chrome; canvas #f5f7f5; forest accent #28594b; ink #202925; borders #e1e7e3. System sans 14px UI/15px content, 22px panel title. Toolbar 72px, sidebar 235px, inspector 360px adjustable. Card radius 8px, subtle border; pastel fills; selected green accent. 8/12/16/24px spacing. Native outline icons and flat rows. Controls and app text remain HTML, not raster. Empty state and import/edit dialogs reuse this palette.

No image is required at runtime. The concept is design documentation, not a UI background.
